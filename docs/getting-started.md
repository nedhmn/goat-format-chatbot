# Getting started

Node 24 and pnpm.

## Run it

```sh
pnpm install
pnpm dev
```

This starts the web app and a local Convex backend on `http://127.0.0.1:3210`, no Convex account needed. The first run downloads the backend binary. The web app's URL is in `.dev/ports.env`.
