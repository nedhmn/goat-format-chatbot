# backend

Convex: schema, queries, mutations, and actions for the chatbot. The agent, its tools, and the scrapers land here. See [docs/architecture.md](../../docs/architecture.md).

## Layout

- `convex/schema.ts`: the database schema. Empty until the data model is settled.
- `convex/_generated`: generated by the Convex CLI and committed, so the gate typechecks without a running backend. Never edit by hand.

## Run

Local only, no Convex account needed:

```sh
CONVEX_AGENT_MODE=anonymous pnpm exec convex dev
```

The CLI keeps local state in `.convex/` and writes `CONVEX_URL` to `.env.local`, both gitignored.
